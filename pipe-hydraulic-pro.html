沿程按 Darcy-Weisbach：hf = λ·(L/D)·v²/2g，λ 由 Colebrook-White 迭代求解。流态处理：Re<2300 取层流解 λ=64/Re；Re≥4000 取 Colebrook 湍流解；2300≤Re<4000 的过渡区无公认关联式，本工具仍按 Colebrook 外推给出单值，同时标注层流解~湍流解的可能区间提示不确定性，该区间结果不应作为设计依据。局部按 hj = Σζ·v²/2g。流速与内径取自上方计算模块的当前结果。ζ 默认值综合美标 Crane TP-410（K = n·fT 法，fT 按 Crane 定义取清洁商用钢管 ε=0.045 mm、以当前内径由 Nikuradse 完全湍流式 0.25/[log₁₀(ε/3.7D)]² 实算——fT 只承担口径缩放，与运行管道的实际粗糙度无关。同一管件小口径 ζ 偏大、大口径偏小，手填默认值大致对应 DN80~150 钢管）、欧标 Idelchik 手册 / KSB（EN 1267 试验体系）/ API 6D·EN 12334、国内《化工原理》《给水排水设计手册》三方交叉取定，悬停每项可见各体系范围与 Crane n 值——需要精确到口径时勾选上方「按口径自动修正」，或直接按厂家样本的 ζ / Kv（欧）/ Cv（美）值覆盖（换算：ζ = 1.6×10⁹·d⁴/Kv²，d 为米，Kv 为 m³/h）。高浓度污泥（>4%）为非牛顿流体，本公式不适用——公式书对 20-40% 污泥直接给定压损 0.5–1.0 bar/m。

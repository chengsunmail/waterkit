① 矩形薄壁堰（Rehbock 公式）

自由出流基本式：

Q = m₀ · ε · σ · b · √(2g) · H^(3/2)

其中 m₀ 为流量系数,ε 为侧收缩系数,σ 为淹没系数（自由出流时=1）。

Rehbock 流量系数（无侧收缩,B=b）：

m₀ = 0.403 + 0.053 · H/P + 0.0007/H

适用条件：0.03 ≤ H ≤ 0.75 m;H/P ≤ 1（ISO 1438）;P ≥ 0.1 m。H/P > 1 时工具提示"超出 Rehbock 适用范围"。

有侧收缩（B > b）：采用 Francis 修正 或 ε 系数,工具中取：

ε = 1 − 0.1·n·H/b（n 为收缩边数,两侧收缩取 n = 2;工具中 ε 下限取 0.5）

注:ε 下限 0.5 为经验取值,以规范 / 手册原文为准。

上游渠宽 B 不得小于堰宽 b;B = b 时 ε = 1。

② 三角堰（V形堰,Kindsvater-Shen 公式）

Q = (8/15) · C_e · tan(θ/2) · √(2g) · (H + k_h)^(5/2) （SI 单位）

C_e 为有效流量系数,k_h 为水头修正值,均随顶角 θ（°）变化（USBR《Water Measurement Manual》/ ISO 1438 曲线的多项式拟合,完全收缩 V 形堰）：

C_e = 0.607165052 − 0.000874466963·θ + 6.10393334×10⁻⁶·θ² k_h [ft] = 0.0144902648 − 0.00033955535·θ + 3.29819003×10⁻⁶·θ² − 1.06215442×10⁻⁸·θ³;k_h [m] = k_h [ft] × 0.3048

90° 时 C_e ≈ 0.578、k_h ≈ 0.89 mm,Q ≈ 1.365 · (H + 0.00089)^(5/2)。拟合式适用 20° ≤ θ ≤ 100°,超出时工具给出提示（120° 为外推,仅供参考）。

适用：0.05 ≤ H ≤ 0.38 m; P ≥ 2H; 上游渠宽 ≥ 3H。

③ 梯形堰 Cipoletti（边坡 1:4）

特点：侧边向外倾斜，补偿侧收缩损失，流量系数近似为常数。

Q = 1.86 · b · H^(3/2) (Cipoletti 公式)

即 m₀ ≈ 0.42,ε ≈ 1.0（自动补偿）。适用：0.06 ≤ H ≤ 0.60 m;b ≥ 3H;P ≥ 2H。

④ 宽顶堰

Q = m · ε · b · √(2g) · H₀^(3/2)

其中 H₀ = H + v₀²/(2g) 为包含行近流速头的全水头（v₀ = Q/[B·(P+H)],迭代中 Q 同样计入 m·ε,迭代 10 次求解,使 H₀ 与最终 Q 自洽）,ε 为侧收缩系数（ε = 1 − 0.2·H/b,下限 0.7,仅 B > b 时计入;经验值,以规范 / 手册原文为准）,m 为流量系数,按"堰顶进口形式"取值:

别列津斯基（Березинский）经验公式（P 为上游堰高,m 随 P/H 连续变化）:

直角进口:m = 0.32 + 0.01 · (3 − P/H) / (0.46 + 0.75 · P/H) （P/H ≥ 3 时 m = 0.32） 圆角进口（r/H ≥ 0.2）:m = 0.36 + 0.01 · (3 − P/H) / (1.2 + 1.5 · P/H) （P/H ≥ 3 时 m = 0.36）

P/H → 0 时两式均趋于理论上限 0.385;直角进口 m 在 0.32–0.385 之间,圆角进口在 0.36–0.385 之间。m 随 H 连续变化,"已知 H 求 Q"与"已知 Q 求 H"两条路径结果互逆一致。默认按直角进口计算。来源:水力学教材（如吴持恭《水力学》）宽顶堰流量系数经验公式,以规范 / 手册原文为准。

宽顶堰适用范围 2.5 ≤ δ/H ≤ 10:δ/H < 2.5 不属宽顶堰,宜按实用堰/薄壁堰计算;δ/H > 10 属长堰,需计入堰顶沿程水头损失,本式会高估流量。

⑤ 淹没出流修正

当下游水位 h_s > 0（下游水面高于堰顶）时:

宽顶堰:h_s / H₀ > 0.8 进入淹没状态;薄壁堰:h_s > 0 即按 Villemonte 式修正

注:薄壁堰真正形成淹没出流,还需下游水位高于堰顶且 z/P < 0.7（z 为上下游水位差）;工具在 h_s > 0 时即按淹没修正,偏于保守。

薄壁堰（矩形 / 三角 / 梯形）采用 Villemonte 公式:

σ = [1 − (h_s/H)ⁿ]^0.385 (矩形、梯形堰 n = 1.5;三角堰 n = 2.5)

宽顶堰按 h_s/H₀ 查表（线性插值）,h_s/H₀ ≤ 0.8 时 σ = 1（表值为经验值,以规范 / 手册原文为准）:

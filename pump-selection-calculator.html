① 系统扬程组成

H = Hg + Hp + hw + H_margin

Hg = z₂ − z₁（出水液面高 − 吸水液面高，m）
Hp = (P₂ − P₁)/(ρ·g) × 1000（两侧表压差 kPa 换算成液柱，m）
hw = hf_s + hf_d + hj（吸水管沿程+局部、压水管沿程、压水管局部）
H_margin：富余量，一般取总扬程的 5-15%。

② 功率计算

Pe = ρ·g·Q·H / 1000 / 3600 [kW]（水功率） Psh = Pe / η_pump / η_trans [kW]（轴功率） Pm = K · Psh [kW]（配套电机，K 为储备系数） P_in = Psh / η_motor [kW]（电机输入电功率，用于电耗计算）

简化公式（清水 ρ=1000, g=9.81）：

P_e = Q·H / 367 [kW] （Q in m³/h, H in m）

③ NPSH 汽蚀校核

NPSHa = (Pa + P₁ − Pv)/(ρ·g) × 1000 − Hs − hf_s [m]

Pa 大气压（按海拔），P₁ 吸水池液面表压（开口水池为 0），Pv 饱和蒸汽压（按水温），Hs 吸水几何高度（吸上为正），hf_s 吸水管总水头损失（沿程 + 进口、底阀、弯头等局部损失；底阀、滤网阻力大，漏计会高估 NPSHa）。

NPSHa ≥ NPSHr + 安全余量（0.5~1.0 m）

最大允许吸水高度：

Hs_max = (Pa + P₁ − Pv)/(ρ·g)·1000 − NPSHr − hf_s − 安全余量

④ 变频调速工作点（假定泵曲线 × 系统曲线）

相似律 Q∝n、H∝n² 只描述泵曲线本身的平移，实际工作点由泵曲线与系统曲线的交点决定；有静扬程时不能直接取 Q'=rQ、H'=r²H。本工具按以下近似求交点（r = n'/n）：

泵曲线（假定二次式）：H = r²·H₀ − k·Q²，H₀ = 关死扬程系数 × H_design，k = (H₀ − H_design)/Q_design² 系统曲线：H = Hst + (H_design − Hst)·(Q/Q_design)²，Hst = Hg + Hp（静扬程，富余扬程计入动扬程部分，曲线过设计点） Q' = Q_design·√[(r²·H₀ − Hst)/(H₀ − Hst)]，H' 代入系统曲线；r²·H₀ ≤ Hst 时泵无法出流 P' = ρ·g·Q'·H' / (η_pump·η_trans) / 1000 [kW]（η 取设计效率，近似；实际降速后效率点会偏移）

节能率 = 1 − P'/Psh。多台同速并联时按总流量计算，结果相同。⚠️ 泵曲线为假定的二次式，仅作估算，以厂家特性曲线为准。
